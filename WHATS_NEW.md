# What's New in v2.1

## ✅ Completed: Final Summary Page

A new **🏆 Final Summary** page has been added to the sidebar.

### Features:
- **Overall Trading Score** (0–100) with rating label (Elite / Above Average / Developing / Needs Work)
- **Period Selector**: Last 7 Days / Last 30 Days / All Time
- **Full Stats Panel**: 12 key metrics in one view
- **Best & Worst Trade** breakdown with notes
- **Grade Distribution** visual bar chart (A+ through F)
- **Strengths & Improvements**: Auto-generated insights from your data
- **Action Plan**: Auto-generated Focus On / Stop / Goals for next period
- **Lessons Learned**: Collected from your trade notes

## ✅ Improved: Auto-Save

- Fixed load-on-startup from Electron file system (not just localStorage)
- Save status indicator: ✓ Saved / ⏳ Saving... / ⚠ Save Error
- Dual save: always writes to both localStorage AND trades.json
- Data loads from file system first on app open

## ✅ Other Improvements
- Recent trades section on dashboard
- Emotion & Session analysis tabs in Analytics
- Monthly performance table in Analytics
- Avg R:R and Total Pips metrics added
- Breakeven trades tracked separately
- Trade count shown in sidebar
- v2.1 version label in sidebar
